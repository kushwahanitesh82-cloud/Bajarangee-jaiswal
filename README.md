## 🚀 How to Upload to GitHub & Host for Free

### Option A: Upload via GitHub Web Browser (Drag & Drop)
1. Go to [GitHub.com](https://github.com) and create a new repository (e.g. `bajarangee-portfolio`).
2. Set it to **Public**.
3. Click **"uploading an existing file"**.
4. Drag and drop all files and folders (`index.html`, `css/`, `js/`, `images/`, `gallery/`, `documents/`, etc.) from this directory into the browser.
5. Click **"Commit changes"**.

### Option B: Upload via Git CLI
Open Terminal / PowerShell in this folder and run:
